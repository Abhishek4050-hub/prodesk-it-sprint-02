
# Cash-Flow - Sprint 2

## Objective
Create a salary and expense tracker using Vanilla JavaScript.

## Features
- Set monthly salary
- Add and delete expenses
- Calculate total expenses and remaining balance
- Validate form inputs
- Save data in LocalStorage
- Display a pie chart using Chart.js
- Switch between dark and light mode
- Download a PDF report
- Convert INR to USD
- Show a low-balance warning

## Technologies
HTML, CSS, Bootstrap, JavaScript, LocalStorage,
Chart.js, jsPDF and Frankfurter API.

## Testing
1. Enter salary and add expenses.
2. Check the remaining balance.
3. Refresh the page and verify saved data.
4. Delete an expense.
5. Test invalid inputs.
6. Test dark mode and light mode.
7. Check the chart and PDF report.
8. Test currency conversion.

I practised DOM manipulation, event listeners,
arrays, functions, validation and LocalStorage.
